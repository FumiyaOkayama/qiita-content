# Dify × Azure AI Search の接続をローカルで確認する

Difyをローカルで起動し、Azure AI Searchと接続して、Azure AI Search側で光学解析した文章をDifyで取得するまでの流れを紹介します。

### 前提条件

- Dockerがインストールされていること

## 1. Difyをローカルで起動する

### Difyの公式リポジトリの取得・コンテナ起動

difyを配置したいパスに移動しクローンする
```bash
git clone https://github.com/langgenius/dify.git
```

コンテナを立ち上げる
```bash
cd dify/docker
docker-compose up -d
```

### Difyアクセス確認

http://localhost/install　へ移動する

新規登録してログインするとDifyの管理画面(http://localhost/apps)が表示される

## 4. Azure AI Searchのスキルセット・データソース・インデックス・インデクサー作成

### スキルセットの作成

1. Azure AI Servicesからキーを確認しておく。

2. ストレージアカウントから接続文字列を確認しておく。

### データソースの作成
Azure AI Searchの管理画面から[データソース]を選択し、[＋データソースの追加]をクリックする。
  ストレージアカウント名を作成したものに、コンテナ名をPDFを配置したものに設定して登録する。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4187508/49310000-e33f-4244-a38f-ce46878abfca.png)

### インデックスの作成
Azure AI Searchの管理画面から[インデックス]を選択し、[＋インデックスの追加]をクリックする。
フィールドに[content]を追加し、検索可能にして[登録]する。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4187508/9fa82ae7-3911-4c88-80a5-45fc91774d45.png)

### インデクサーの作成
Azure AI Searchの管理画面から[インデクサー]を選択し、[＋インデクサーの追加]をクリックする。
データソース、インデックス、スキルセットにそれぞれ作成したものを選択し、[一度のみ]を選択して[登録]する。

## 5. インデクサーの実行

インデクサーは「一度のみ」を選択していると、作成後すぐに実行される。
インデクサーの画面でステータスが[成功]になっていることを確認し、インデックスへ移動する。

インデックスで[*]として検索し、PDFの内容が登録されていることを確認する。
![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/4187508/c089a1cf-1627-44c6-9d6c-ea9abfeadaca.png)

## 6. DifyでAzure AI SearchのAPIをコールしてみる

Difyの管理画面で上部の[ツール]を選択し、[カスタム]から[カスタムツール]を作成する。

- URLはPortalからAI Searchのエンドポイントを確認し、https://<リソース名>.search.windows.netにする
- test-index-feild-on となっているところは、作成したインデックス名に置き換える
- api-versionは2023-11-01を指定する

```json
{
  "openapi": "3.0.0",
  "info": {
    "title": "Azure Cognitive Search Integration",
    "version": "1.0.0"
  },
  "servers": [
    {
      "url": "https://ai-search-jpapneast.search.windows.net"
    }
  ],
  "paths": {
    "/indexes/test-index-feild-on/docs/search": {
      "post": {
        "operationId": "postSearchResults",
        "parameters": [
          {
            "name": "api-version",
            "in": "query",
            "required": true,
            "schema": {
              "type": "string",
              "default": "2023-11-01"
            }
          }
        ],
        "requestBody": {
          "required": true,
          "content": {
            "application/json": {
              "schema": {
                "type": "object",
                "required": ["search"],
                "properties": {
                  "search": { "type": "string" },
                  "top": { "type": "integer" },
                  "select": { "type": "string" }
                }
              }
            }
          }
        },
        "responses": {
          "200": {
            "description": "Successful response",
            "content": {
              "application/json": {
                "schema": { "type": "object" }
              }
            }
          }
        }
      }
    }
  }
}

```

Dify側でテストを実行すると、インデックスの内容が取得できたことが確認できる。
